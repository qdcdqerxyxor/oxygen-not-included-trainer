## 📖 About

Oxygen Not Included by Klei Entertainment (2019) is a colony survival sim set inside a subterranean asteroid. You manage duplicants' oxygen, food, temperature, and stress while building increasingly complex automated systems. Late-game requires engineering solutions that would challenge real thermal physicists.
